# Jim Arul UX Portfolio

A one-page portfolio focused on UX research, product design, behavioral science, and human-centered technology.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/ (root)**.
5. Save.

The site should then be available at:

`https://jda253-dev.github.io/portfolio/`
